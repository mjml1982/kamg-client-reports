2
Create a Workflow with an Inbound Webhook Trigger

This workflow receives the form data and creates or updates a GHL contact automatically.

  1. Go to Automation → Workflows → + New Workflow
  2. Set the trigger to Inbound Webhook
  3. GHL will generate a unique webhook URL — copy this URL, you'll need it in Step 3
  4. Add action: Create / Update Contact
  5. Map the incoming webhook fields to contact fields:
    • firstName → First Name
    • lastName → Last Name
    • email → Email
    • phone → Phone
    • customField.cod_work_category → COD Work Category
    • customField.cod_professional_role → COD Professional Role
    • customField.cod_service_description → COD Service Description
    • customField.cod_decision_maker → COD Decision Maker
    • customField.cod_sms_consent → COD SMS Consent
    • customField.cod_appointment_date → COD Appointment Date
    • customField.cod_appointment_time → COD Appointment Time
  6. Optionally: add a tag (e.g., COD-Applicant), send a confirmation email, or add to a pipeline stage
  7. Publish the workflow
↓
3
Add the Submit Handler to the Form HTML

Find the section in the form's JavaScript that handles the final confirmation step. Add this function and call it before showing the confirmation screen.

Replace YOUR_WEBHOOK_URL with the URL from Step 2.

// --- GHL Submission Handler ---
const GHL_WEBHOOK_URL = 'YOUR_WEBHOOK_URL_HERE';

async function submitToGHL(formData) {
  const nameParts = (formData.full_name || '').trim().split(' ');
  const payload = {
    // Native GHL contact fields
    firstName:  nameParts[0] || '',
    lastName:   nameParts.slice(1).join(' ') || '',
    email:      formData.email,
    phone:      formData.phone || '',

    // Custom fields — keys must match exactly what's in GHL
    customField: {
      cod_work_category:      formData.work_category,
      cod_professional_role:  formData.professional_role,
      cod_service_description:formData.service_description,
      cod_decision_maker:     formData.decision_maker,
      cod_sms_consent:        formData.sms_consent ? 'Yes' : 'No',
      cod_appointment_date:   formData.appointment_date,
      cod_appointment_time:   formData.appointment_time,
    }
  };

  try {
    await fetch(GHL_WEBHOOK_URL, {
      method:  'POST',
      headers: { 'Content-Type': 'application/json' },
      body:    JSON.stringify(payload)
    });
  } catch (err) {
    console.error('GHL submission failed:', err);
  }
}

// Call this on the final step, e.g.:

// showConfirmationScreen();
⚠ Make sure collectedFormData is the object you're building across all form steps — the keys above must match what you're storing in your form state.
↓
4
Paste into GHL HTML Widget

Once the webhook URL is wired in and tested locally:

  1. Open your GHL Funnel or Website page editor
  2. Add a Custom Code / HTML widget to the page
  3. Paste the complete form HTML (including <style> and <script> tags) into the widget
  4. Save and preview — the form should render and submit exactly as designed
✓ GHL webhooks accept cross-origin requests, so no CORS issues — the fetch call works directly from the browser without a backend.
